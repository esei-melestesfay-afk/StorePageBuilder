# StorePageBuilder

Ett enkelt lokalt verktyg för att snabbt skapa färdiga Shopify-sidor.

## Användning

1. Skriv **Brand**, **Supportmail** och **Produkt**.
2. Välj sida.
3. Klicka **Kopiera**.
4. Klistra in i Shopify.

Fasta uppgifter i mallarna:
- Leverans: **6–10 arbetsdagar**
- Adress: **Långgatan 25 F, Sollefteå**

## Starta på Windows

```powershell
cd "$HOME\Desktop\StorePageBuilder"
py -3 server.py
```

Du kan också köra `start.ps1` från PowerShell.

Appen använder ingen AI och inga API-nycklar. Allt körs lokalt.
